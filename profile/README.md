# Ckodex Labs

**Verifiable Intelligence.** Proof-native infrastructure for governing AI systems — where every consequential decision carries the evidence that justifies it.

We build the layer between AI capability and the obligation to prove it behaved: signed evidence bundles, attestation chains, and supply-chain provenance that **hold up under audit instead of asking for trust.**

### Focus areas

| | Area | What it means |
|---|---|---|
| 🛡️ | **Proof-carrying governance** | Decisions emit attestations, not just logs. |
| 📦 | **Evidence bundles** | Portable, signed, audit-ready artifacts. |
| 🔗 | **Supply-chain integrity** | Provenance and attestation across the build-to-deploy path. |
